# Race Tournament — сборка APK

Этот проект уже настроен так, что GitHub сам соберёт вам установочный `.apk` —
никаких Android Studio и командной строки на своём устройстве не нужно.

## Что готово сейчас (этап 1)
- Главное меню (Создать игрока / Турнир / Разовая гонка)
- Полный экран «Создать игрока»: фото из галереи (любой формат — автоматически
  приводится к квадрату), ник (1–25 символов, подсветка красным при ошибке),
  карточки игроков со скроллом, удаление с подтверждением, редактирование
- Данные сохраняются на устройстве (IndexedDB) — не потеряются при перезапуске
- «Турнир» и «Разовая гонка» — пока заглушки, будут в следующих этапах

## Как получить .apk

1. Зайдите на github.com, зарегистрируйтесь (если ещё нет аккаунта).
2. Создайте новый репозиторий (New repository), любое имя, приватный или
   публичный — не важно.
3. На странице пустого репозитория нажмите **uploading an existing file** /
   **Add file → Upload files**.
4. Перетащите туда все файлы и папки из этого проекта (сохраняя структуру:
   `www/`, `.github/`, `package.json`, `capacitor.config.json`, `.gitignore`).
5. Нажмите **Commit changes**.
6. Откройте вкладку **Actions** вверху репозитория — там автоматически
   запустится сборка (займёт 3–6 минут).
7. Когда сборка позеленеет (галочка ✅), откройте её и внизу страницы в
   разделе **Artifacts** скачайте `race-tournament-debug-apk` — внутри будет
   готовый `app-debug.apk`.
8. Перенесите `.apk` на планшет (через кабель, облако или телеграм) и
   установите — Android спросит разрешение на установку из неизвестных
   источников, это нормально для debug-сборки.
